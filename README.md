# Personal Portfolio Website

A simple and responsive personal portfolio website for **Mahlet Ayele**.

## Features

* Home section
* About Me section
* Skills section
* Projects section
* Contact form
* Responsive design
* Project filtering
* Animations and typing effect

## Technologies

* HTML
* CSS
* JavaScript
* Boxicons
* Typed.js
* ScrollReveal

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
